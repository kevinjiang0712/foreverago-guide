# 独立站演示内容包

这些是虚构资料，用来验证模板复用，不是游戏事实，也不适合直接公开索引。

| 样例 | 语言 | 主题 | 内容差异 |
|---|---|---|---|
| site-a | 英语、日语 | onimusha 明暗组合 | 覆盖 11 种模板；每种都有完整英日对应页面。 |
| site-b | 英语、简体中文 | Onimusha 基础 + 蓝色与圆角配置，默认日间 | 换站名、分类 ID/网址/顺序、实体与文章名称、记录数量及语言；中文只提供首页和一篇攻略，未翻译文章不生成占位内页。 |

使用母模板中的命令创建独立副本：

```bash
npm run create:site -- --target /absolute/path/to/new-game-site --sample a
```

选择 B 时将最后的 `a` 改为 `b`。复制后替换根目录 `config/`、`content/`、`public/media/`；`examples/site-a` 留作隔离框架测试，不用改成真实游戏内容。

完整换站验证使用 `npm run verify:reuse`：从两个样例分别复制、安装锁定依赖、构建和逐页检查，再比较源框架和两站的文件内容摘要。没有自动部署操作。
