# 用 AI 维护当前站

复制下方文字，在最后补上遇到的问题、页面网址和期望结果。不需要描述技术实现。

```text
请维护当前游戏站。先阅读项目 README、AGENTS.md 和 docs/usage/maintenance.md，
确认正在操作的项目目录、Git 分支与未提交修改。

我的问题和期望：
【在这里写：哪个页面、什么情况下出现问题、希望怎样显示或操作】

请自行定位它属于哪一层：
- config：站点标识、主题、导航分类、官方链接、语言、SEO 默认项；
- content / public/media：游戏显示名称、文章、首页文案、实体数据、翻译和素材；
- src / scripts：布局组件、交互、内容生成和校验逻辑。

保持现有模板的楼层、视觉、动效和响应式规范。优先修改配置或内容；
确实是框架缺陷时，在当前站做最小代码修复，不建立跨站公共依赖。
不要覆盖我已有的修改，不改其他游戏站。先保留可回退的本地 Git 记录。

检查真实来源；未知信息继续标记未知。不要用示例数字填空，也不要通过关闭校验、
隐藏内容、虚构成功提示或跳过失败测试来解决问题。

完成已授权的工作并运行与改动有关的检查。涉及页面时，用本地浏览器验证
问题原本的触发步骤和修复后的结果；涉及内容或路由时运行内容检查及构建。
有明确错误先修复，只有缺少必要资料才提出具体问题。

最后简要告诉我：修改了哪一层、修复了什么、实际通过的检查、
本地预览入口和 Git 回退点。未执行的检查不要写成通过。
未经我明确要求，不部署、不推送远程、不发送消息给其他人。
```

## 可以直接补在末尾的问题

- 手机打开某篇文章，标题被截断。请保持当前设计，修复后检查短标题和长标题。
- 这个筛选按钮点击后结果没变化。请让数量、卡片和空结果提示保持一致。
- 我要新增这些关键词的攻略。请只改内容和必要分类配置，保持稳定内容 ID，列出新增网址。
- 我要给这几篇文章增加日语。没有翻译的其他文章不要生成占位页，检查语言切换和 SEO 对应关系。
- 我只想换主题色和字体。请从主题配置入口修改并验证日间、夜间和手机效果。

这里的本地 Git 是当前站自己的历史。修复某个独立站不会自动修改母模板或其他站。
