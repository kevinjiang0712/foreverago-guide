# 添加一个可使用角色的详情

将下面的提示词交给 AI，并提供核实过的资料与素材：

> 在当前独立站中添加角色「角色名」的详情页。先读 AGENTS.md、docs/usage/template-fields.md 的 character-detail 章节和现有 demo-guide-detail 示例。使用 character-detail 固定五个区域，保留现有样式、组件与动效。只修改内容和必要的分类配置，不修改框架。
>
> 角色资料：在此提供名称、定位、简介、属性及测量条件。
> 技能资料：在此提供技能名称、类型、效果、图标、消耗与冷却。无该字段填 null；未确认但适用的字段明确写未确认。
> 获取资料：在此提供前置条件、地点、步骤。
> 素材与来源：在此提供可核验来源、图片文件、真实更新时间和版本。
> 需要的语言：在此列出；不伪造缺失翻译。
>
> 复用已有角色记录，或新增 type=character 记录；详情 JSON 用 characterId 关联，角色 contentId 保持 null，由索引自动连接。将新角色 ID 加入角色库 characterIds。不要捏造数字、来源、图片或更新时间。未知属性值、前提与地点用 null，缺图保留图槽。真实内容不能以 demo 掩盖错误；演示样例也不能改成真实资料来通过发布检查。
>
> 完成内容校验、构建和浏览器验证，确认列表点击、五个区域、语言链接、移动端目录与缺省字段显示。报告实际结果和本地 Git 提交，不推送或部署。
